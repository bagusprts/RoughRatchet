# RoughRatchet

RoughRatchet enables efficient, event-driven processing of decentralized transactions within a modular system architecture.

RoughRatchet is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/RoughRatchet.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure RoughRatchet, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
